# 'AI 신입사원' 입사 5요소 셋업 워크시트 (Phase 0)

AI를 챗봇이 아닌 '직원'처럼 쓰려면 아래 5요소를 채운다. 작성 후 대표(권한자)가 승인.

| 요소 | 질문 | 입력 |
|---|---|---|
| 1. 이름·성향 (Soul) | 에이전트 이름/말투/응답 방식은? | |
| 2. 기억 (Memory) | 회사 기본정보, 대표 성향, 자주 쓰는 지시는? | |
| 3. 보고 채널 (Channel) | 어디로 보고? (이메일/슬랙/카톡/텔레그램) | |
| 4. 업무 스케줄 (Schedule) | 언제 먼저 말 걸어 시작? (매일 아침/매월 10일 등) | |
| 5. 업무 매뉴얼 (Manual) | 어떤 일을 어떻게 처리? (가이드라인) | |

## 권한자 승인
- [ ] 위 5요소가 회사 운영 방침과 일치하는가? (대표/창업자 확인)
- [ ] 보고 채널·데이터 접근 권한이 적절한가? (과도한 권한 부여 주의)

> ⚠️ 채널 연동·데이터 접근 설정 시 민감정보 노출 범위를 최소화하라.
