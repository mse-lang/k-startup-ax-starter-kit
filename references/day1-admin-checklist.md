# Day-1 창업 행정 체크리스트 (Phase 2)

순서대로 안내. 각 항목 공식 처리처는 [gov-source-links.md](gov-source-links.md) 참고.

## A. 설립 단계
- [ ] 사업 형태 결정 (개인사업자 vs 법인) — 자본금·세금·투자유치 고려
- [ ] (법인) 상호·사업목적·자본금·주주/이사 구성 확정
- [ ] (법인) 온라인 법인설립시스템(startbiz) 또는 인터넷등기소(iros)로 설립등기
  - 참고: 자본금 10억원 미만 회사는 상법상 감사 선임 **의무 아님(임의)**. "감사 필수" 아님.
- [ ] 법인 등기사항전부증명서(등기부등본) 발급

## B. 사업자 / 세무
- [ ] 국세청 홈택스에서 사업자등록 신청 (개시일로부터 20일 이내)
- [ ] 업종 코드·간이/일반과세 여부 확인
- [ ] 공동인증서(범용 또는 은행용) 발급
- [ ] 사업용 계좌 개설, 홈택스에 사업용 계좌 등록
- [ ] 전자세금계산서 발급 환경 준비 (발급 기한: 공급일이 속한 달의 다음 달 10일까지)

## C. 보험 / 노무 (직원 채용 시)
- [ ] 4대보험 사업장 성립신고 (4insure)
- [ ] 근로계약서 작성·교부 (필수)
- [ ] 5인 미만 사업장 적용 제외 규정 확인 (연장·야간·휴일 가산수당, 연차 등)

## D. 초기 거버넌스
- [ ] 사내 공식 문서 양식 확정
- [ ] 결재/권한 분리 규칙
- [ ] 공유 계정·비밀번호 관리 정책
- [ ] 필수 일정 등록 (부가세·원천세·급여·4대보험 신고일)

> ⚠️ 일반 안내이며 법률·세무 자문 아님. 기한·요건은 시점별로 공식 출처와 전문가로 재확인.
